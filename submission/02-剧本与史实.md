# 01 · 剧本与史实

## 一句话

孙女要卖掉爷爷开了四十年的早茶店。爷爷不拦，只让她在最后一个早晨，陪他把一碟干丝烫三遍。

## 人物

- **爷爷**，70，早茶店老师傅。瘦，白背心，深蓝围裙，肩上一条灰毛巾。话极少，手上有刀疤。不说「舍不得」，只说「干丝不等人」。
- **孙女**，28，在上海做设计。黑外套，灰卫衣，一条**鲜红围巾**——全片唯一强色。她带着转让合同回来，也带着「这店一年挣不了几个钱」的账。
- **老客**，65，每天来，只坐 3 号桌。全片只给剪影。

## 结构（五幕）

1. **四点**（0:00–0:33）泰州还没醒，一间店先醒了。水在响。
2. **一碟干丝**（0:33–1:31）合同放在案板上，没人看它。爷爷只教手艺。
3. **一副多出来的碗筷**（1:31–2:04）店里的规矩不是「快」，是「留着」。
4. **汤白了**（2:04–2:28）捣碎才白。孙女问「人呢」，爷爷不答——片子替她答。
5. **围裙**（2:28–3:54）店卖掉了，手艺跟着人走了。第二年春天，上海，她一个人烫三遍。

## 为什么不是文旅宣传片

官方要「泰州故事」、不要「纯商业推广」。这条片子的主角是一间会关掉的店，落点是「一个人也要吃好一顿早饭」——**不推介任何景点、老字号、商品**，也不出现真实店招。地方性靠三样东西落地：俗语（皮包水）、手艺（三烫）、器物（干丝 / 鱼汤 / 青花碗 / 竹蒸笼 / 木案板）。
