# 02 · 风格、人物与「人物一致」怎么验

## 一、风格

**一句话**：一本会动的宣纸画册。写意水墨淡彩，四色，一块朱红。

| 项 | 定值 | 为什么 |
| --- | --- | --- |
| 画法 | 写意水墨 + 淡彩（不是「水墨风滤镜」，是墨线为主、彩只上在皮肤与器物上） | 与泰州的地方气（盐运、水乡、老街）对；也与「漫剧」常见的日漫厚涂拉开距离 |
| 色板 | 墨黑 `#1B1A17` / 宣纸米白 `#F3EDE1` / 茶褐 `#8A5A34` / 朱砂红 `#B33A2B` | 只有四色，人物与器物才读得出「同一本画册」 |
| 朱红的使用 | **只在两处给强色**：孙女的围巾、灶口的火 | 让评委在缩略图里也能一眼认出女主 |
| 底 | 宣纸：大块不匀 + 细纤维 + 颗粒（程序生成，1080×1920） | 图版边缘不硬切，画册感来自纸 |
| 台词呈现 | 白字 + 墨描边 + 投影（不挂气泡） | 漫剧惯例；气泡会把水墨压成漫画 |
| 拟声 | 毛笔字「嗤」「哗」各一次，落在蒸汽与水柱上 | 漫画的语法，只给两处，不滥用 |
| 转场 | 硬切为主；五处幕间淡黑（0.3 s） | 水墨怕花哨转场 |

## 二、人物设定（图生图的锚）

| | 爷爷 | 孙女 |
| --- | --- | --- |
| 年龄 | 70 | 28 |
| 记忆点 | 肩上一条**灰毛巾** + 深蓝围裙 + 手背一道旧疤 | 齐耳短发 + 一条**鲜红围巾** |
| 脸 | 瘦、眼窝深、眼尾下垂、法令纹深、嘴角向下 | 粗眉、单眼皮、鼻梁直、嘴唇薄、下巴略尖 |
| 参考图 | `assets/char/ye.png` | `assets/char/sun.png` |

一致性靠三层，缺一层就会漂：

1. **图生图**：每张含人物的图版都拿设定图当 `image1`（双人镜头 `image1` + `image2`），提示词第一句写「以参考图中这位…为准，同一个人，换姿势与光线」。
2. **服装锁定**：毛巾 / 围巾这两个「记号」在提示词里每次点名——它们是评委辨认同一人的捷径。
3. **后期统一**：所有图版走同一条渲染色链（同一纸底、同一暗角、同一颗粒、同一 4 色量化），把不同次生成的色温差压平。

## 三、「人物形象前后一致」怎么验（AC-9）

官方把这条写进了规格，所以它不能只靠眼看。

`scripts/verify.py --faces` 对**每一张含人物脸**的图版做三件事：

1. **裁脸**：按 `story.FACES` 里登记的框（人手标定，随图版走）裁出脸区，缩到 96×96 灰度；
2. **归一化互相关**（NCC）：与设定图同一块脸区比，输出 `[-1,1]`；
3. **结构相似度**（SSIM，简化版）：比亮度结构，避开纯色块骗分。

判据：**NCC ≥ 0.35 且 SSIM ≥ 0.45** 记为「同一人」；每张图版都要留 `proof/faces/` 的并排图（左设定图、右该镜头），供人复核。

> 阈值不是拍脑袋：先用设定图自比（NCC=1.0）与两张不同人物互比（NCC≈0.1）标定区间，再取中间偏保守的一侧。实测值写在 `proof/faces/report.md`。

## 四、已知弱项（提前认账）

- 水墨笔触的「脸」在低分辨率下细节少，脸区相关性对角度敏感；侧脸、低头、被蒸汽遮半张脸的镜头，NCC 天然偏低。这类镜头在 `story.FACES` 里标 `hard=True`，判据放宽一档（NCC ≥ 0.25），并在报告里单列。
- 手部特写不参与人脸判定（没有脸），但服装记号仍在画面里。
- 片子整体偏「静」，靠镜头推移与声音推进；如果评委期待的是快切爽剧，这是本片的取向性风险。
